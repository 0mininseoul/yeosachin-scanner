# Week 1 얼리버드 실행 자산 (복붙용)

작성일: 2026-07-25 · 상위 기획: `docs/superpowers/specs/2026-07-25-marketing-strategy-design.md`
목표: 낯선 사람 **10명 결제** (Basic 6,900 / Standard 9,900, 각 선착순 10, 24시간 내 결과)
톤: **밈·재미** · 원칙: **판매자 톤 제거 · 실계정/실명 노출 금지 · "재미 목적" 면책 상시**

---

## ⚠️ 게시 전 체크리스트 (매 게시마다)

- [ ] 실존 인물/실계정/얼굴이 소재에 없는가 (데모는 전부 가상 데이터)
- [ ] 해당 커뮤/방의 홍보 규칙 위반 아닌가 (직접 링크 금지 채널 확인)
- [ ] "판매자"로 보이지 않는가 (1인칭 경험담 톤인가)
- [ ] 면책 한 줄 들어갔거나, 최소한 "재미로" 뉘앙스인가
- [ ] UTM 링크 사용 (utm_source/medium/campaign=earlybird)

## 1. 결과 데모 카드 3종 (스크린샷 최적화 · 9:16)

> 목적: 궁금증 갭(curiosity-gap)으로 신규 유입. **고위험 1명은 블러**, 전체는 본인이 돌려야 보이게.
> 하단 워터마크 공통: `AI 위장 여사친 판독기 · [URL]` + 작게 "재미 목적 · AI라 100% 정확 X"

### 카드 A — "여자 맞팔 발견" 훅 (도입용)
```
┌─────────────────────────────┐
│  @내남친 맞팔 계정 분석 결과   │
│                             │
│   👨 남성 87명 (57%)         │
│   👩 여성 47명 (31%)   ← 문제 │
│   ❓ 알수없음 18명 (12%)      │
│                             │
│   "여자만 47명이었다..."      │
│                             │
│  🔴 이 중 고위험 1명 발견     │
│  ───────────────────────    │
│  AI 위장 여사친 판독기 · URL   │
└─────────────────────────────┘
```
캡션 예: `남친 인스타 돌려봤다가 여자 맞팔 47명 뜬 사람 손 🙋‍♀️`

## 2. 채널별 "썰" 대본

### 2-1. 카카오 오픈채팅 (연애상담·썸·연애고민 방) — ★최우선
> 톤: 대화 중 자연스럽게. **링크 먼저 X**, "이거 뭐냐" 물으면 그때. 방 규칙 준수, 하루 1방 1회.

**대본 ① (고민 상담 흐름에 얹기)**
```
아 나 어제 좀 웃긴 거 했는데
남친이 인스타 여자들 맞팔 많아서 계속 신경쓰였거든
근데 AI가 대신 분석해주는 거 있어서 걍 재미로 돌려봤음 ㅋㅋ
여자 맞팔 47명 중에 고위험이라고 1명 딱 집어주는데
총평 읽고 개웃곀ㅋㅋ 소름 반 웃음 반
```
(누가 "그거 뭐야/링크" → 그때 공유 + "재미로 보는 거임 진지 ㄴㄴ")

**대본 ② (가볍게 던지기)**
```
님들 남친 인스타 여사친 판독해주는 거 해봄?
공개 계정만 되는 거고 AI가 위험한 순서로 정렬해줌 ㅋㅋㅋ
나 방금 돌렸는데 1등 나온 애 프로필 보고 확신함;;
```

### 2-2. 여초 커뮤 (더쿠 · 인스티즈) — ★최우선
> 톤: 익명 반말/음슴체, 이모티콘. **직접 홍보 금지 → "썰" + 이름은 댓글에서 물어보게.**

**더쿠 유머/연애 게시판용**
```
제목: 남친 여사친 AI로 판독했다가 현타옴 ㅋㅋㅋㅋ

그냥 재미로 돌린 거임 진짜
남친 인스타 아이디 넣으니까 맞팔 중에 여자만 골라서
위험한 순서대로 정렬해줌 (공개 계정만 되는 거)
1등으로 뜬 애 총평이 "게시물마다 흔적 남기는 타입"래 ㅋㅋㅋㅋ
아 나 이거 왜 돌려서 밤새 인스타 스토킹함;;;
(스샷 — 블러 카드 B)

+ AI라 100% 아니고 그냥 재미로 보는 거니까 다들 진지 ㄴㄴ
```
(댓글에서 "이거 뭐야ㅠ" → "○○ 검색하면 나옴" 자연 안내)

**인스티즈용 (더 짧게)**
```
제목: 이거 남친 있는 사람들 하지마셈 (밤샘 확정)

남친 여사친 위험도 AI가 순위 매겨주는 거 돌렸는데
왜 굳이 알아버린 거지 나는....
(스샷 — 카드 C 밈)
```

### 2-3. 에브리타임 (익명 게시판)
> 톤: 대학생 익명. **직접 링크·서비스명 지양, 검색 유도.** 유료 냉담하니 "재미" 강조.

```
제목: 남친 인스타 여사친 판독해주는 거 해봄 (스압주의)

시험기간에 현타와서 걍 재미로 돌림
AI가 남친 맞팔 여자들 위험도 순위 매겨주는데
6900원이라 커피값이라 생각하고 함 ㅋㅋ
결과? ... 그냥 안 볼 걸 그랬어 (근데 후회 안 함)
검색하면 나옴 이름은 좀 그래서 안 씀 ㅋㅋㅋ
```

### 2-4. 스레드 (22명 계정 · 매일 축적)
> 톤: 짧은 밈. 매일 1~2개. 카드와 함께.

```
[1] 남친 여사친 47명 중에 AI가 1명 콕 집어준 순간 등이 서늘해짐 🥶
[2] "재미로만 보세요" 하는데 재미로 안 봐지는 게 함정
[3] 6,900원 = 남친 여사친 순위표. 싸다 vs 판도라 상자 (투표)
[4] 결과 캡처 (블러 카드 B) + "우리 남친 1등은 누구게~"
```

### 2-5. X (0명 계정, 스레드 크로스포스트)
> 스레드 문구 그대로 크로스포스트 + 해시태그 `#여사친판독 #연애` 최소 사용.

## 3. 오픈채팅/커뮤 침투 운영 스크립트

**진입 원칙 (community-marketing)**
1. **먼저 녹아들기:** 새 계정으로 방/게시판 들어가면 최소 1~2일은 그냥 대화·댓글만. 바로 썰 X (스팸 인식 → 밴).
2. **1인칭 경험담만:** "제가 만든/좋은 서비스" = 즉사. "나 이거 해봤는데" = 생존.
3. **링크는 요청 시에만:** 여초 커뮤·에타는 링크 남발 = 홍보글 삭제/밴. "검색하면 나옴"으로 우회.
4. **분산:** 방/커뮤마다 계정·문구 로테이션. 같은 글 복붙 티 내지 않기.
5. **타이밍:** 저녁 9~11시(타겟 활동 피크)에 게시.
6. **댓글 응대:** "이거 뭐야" 나오면 30분 내 자연스럽게 답 → 대화가 알고리즘·신뢰 다 살림.

**하루 운영 루틴(예시)**
- 21:00 오픈채팅 1방 대본 ① 투척
- 21:30 더쿠 or 인스티즈 썰 1개
- 22:00 스레드 밈 1개 + 어제 글 댓글 응대
- 23:00 반응 체크 → UTM으로 어디서 유입됐나 기록

## 4. 희소성 푸시 라운드 (D5~D7)

> 슬롯 소진 상황을 실시간 무기로. "N/10 남음" 스샷과 함께.

```
[D5] 얼리버드 6,900원 자리 이제 3자리 남았대... 고민하던 사람 지금임
[D6] 곧 마감 → 정가 13,900 복귀. 커피 한 잔 값에 마음의 평화(?) 마지막 기회
[D7 마감] 마감됨. 다음 기회는 대기자 등록하면 알려준대 (waitlist 링크)
```

## 5. 문의 응대 템플릿 (댓글/DM 공통)

- **"믿을만해?"** → "AI라 100%는 아니고 재미로 보는 거예요! 공개 계정 정보만 봐요"
- **"비공개 계정은?"** → "비공개는 분석 안 되고 목록만 떠요~ 공개 계정만 판독"
- **"결과 언제 와?"** → "지금 얼리버드라 24시간 안에 이메일로 와요"
- **"남친이 알아?"** → "전혀요, 공개된 정보만 보는 거라 상대는 몰라요"
- **비난/시비** → 논쟁 X. "재미로 하는 거예요~" 한 번만, 이후 무대응.
