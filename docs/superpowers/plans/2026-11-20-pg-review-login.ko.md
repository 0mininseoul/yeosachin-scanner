# 토스페이먼츠 심사용 로그인 구현 계획

- [x] 일반 로그인 페이지와 홈페이지 로그인 모달에 ‘이메일로 로그인’을 표시한다. 등록한 이메일과 서버의 비밀번호 검증값으로 인증하고 구매 확인 화면에만 유효한 서명 세션을 발급한다. 로그아웃 시 쿠키를 만료시키고 일반 로그인으로 돌아간다.
- [x] 서비스의 요금제 카드와 가격·구매 안내를 재사용한다. 합성 사례로 요금제 선택 및 주문 내용 확인을 제공하고 주문이나 외부 결제 요청을 생성하지 않는다.
- [ ] 타입 검사, 인증 회귀 검사, 독립 리뷰와 PR 검사를 진행한다.
- [ ] 운영 환경의 기존 이메일·비밀번호를 사용한다. 배포 후 홈페이지 로그인 모달과 일반 로그인 페이지에서 이메일 로그인, 잘못된 비밀번호, 구매 내용 확인, 로그아웃을 검증한다.
