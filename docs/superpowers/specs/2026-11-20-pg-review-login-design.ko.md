# 토스페이먼츠 심사용 로그인

심사 담당자에게 운영 도메인의 별도 로그인 URL과 전용 이메일·비밀번호를 발급한다. 서버에 설정된 전용 계정만 허용한다. 심사 URL에만 전송되는 서명 쿠키를 사용하며, 비밀번호 검증값과 세션 키는 운영 환경에 보관한다.

로그인 후 실제 서비스와 같은 요금제 카드, 상품 금액, 구매 안내, 이용약관을 볼 수 있다. 합성 사례를 사용해 Basic과 Standard 구매 내용을 확인한다. 이 화면에서는 주문을 생성하거나 결제사를 호출하지 않는다. 토스페이먼츠 직접 연동은 심사 승인 이후 작업으로 다룬다.

운영 배포 후 로그인하지 않은 방문자, 잘못된 비밀번호, 심사 계정의 로그인 및 로그아웃, 상품 금액, 주문 내용 확인을 검증한다.
