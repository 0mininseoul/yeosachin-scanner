## 0. 한눈에 보기

| 구간 | 기간 | 목표 | 주력 레버 | 성패의 관건 |
|------|------|------|-----------|-------------|
| **Phase 1 — 얼리버드** | 지금~1주 | 낯선 사람 **10명 결제** | 커뮤니티 떡밥 시딩 + 얼리버드 희소성 | 진입 가능한 여초 커뮤/오픈채팅 확보 |
| **Phase 2 — 스케일** | 프로덕션 런칭 후 30일 | **1,000명 결제** | 숏폼 엔진(ABG 포함) + 인플루언서 시딩 + 추천 루프 | 숏폼 1~2개의 breakout(10만+ 조회) |

**정직한 난이도 평가**
- **10명(1주):** 노력 대비 거의 확정. 10명은 절대수가 작고, 얼리버드 희소성이 강력한 전환 장치. 관건은 "결제 안 하는 지인" 대신 낯선 사람 10명을 만날 채널 진입.
- **1,000명(1달):** 스트레치 목표. 선형 성장으로는 불가능하고 **숏폼 breakout 1~2개에 의존**한다. 그래서 Phase 2는 "안정적 성장"이 아니라 "슛 횟수 극대화(volume of shots)" 전략으로 설계한다.

## 1. 목표 & 성공지표(KPI)

### 1.1 North Star
결제 완료 수(paid orders). 단, 선행지표를 함께 본다.

### 1.2 퍼널 지표 (AARRR)
- **Acquisition:** 랜딩 방문(UTM별 소스), 커뮤/숏폼 도달·저장·공유
- **Activation:** 로그인 완료 → 분석 대상 ID 입력 시작(`analysis_started`)
- **Revenue:** Groble 결제 완료(`earlybird_checkout_completed` / paid order)
- **Referral:** 결과 공유 카드 클릭, 추천 코드 유입
- **Retention(Phase 2):** 맞팔 업데이트 알리미 전환, 재분석

### 1.3 Phase별 목표치
| 지표 | Phase 1(1주) | Phase 2(1달) |
|------|------|------|
| 결제 | 10 | 1,000 |
| 랜딩 방문 | ≥ 400 | ≥ 33,000 (blended CVR 3% 가정) |
| 블렌디드 방문→결제 CVR | ≥ 2.5% | ≥ 3% |
| 숏폼 게시 개수 | 5~7 | 60~90 (일 2~3개, 슛 횟수) |
| 커뮤 떡밥 게시 | 6~10 | 상시 |

> **퍼널 역산:** 1,000결제 ÷ 3% CVR ≈ 33,000방문/월 ≈ 1,100방문/일. 노광고로 이걸 만들려면 숏폼 최소 1~2개가 10만~100만 조회로 터져야 한다. 따라서 "터질 확률"을 높이는 게 Phase 2의 전부다 — 훅 다양화 + 게시량 + 크리에이터 레버리지.

## 2. 포지셔닝 & 메시지

### 2.1 톤: 밈·재미 (표층) + 희소성·불안 (전환 장치)
- **끌어오는 카피(재미):** "남친 여사친 판독기 돌려봤는데 결과 실화냐 ㅋㅋㅋ"
- **닫는 카피(희소성):** "얼리버드 선착순 10명, 정가 13,900 → 6,900(50% off) · 곧 마감"
- **면책(항상):** "AI 분석은 100% 정확하지 않으며 재미 목적입니다" — 톤 유지 + 백래시 방어 겸용.

### 2.2 메시지 계층 (copywriting 스킬 적용)
1. **후킹:** 궁금증 갭 — "내 남친이 맞팔 중인 여자들, 누가 제일 위험할까?"
2. **공감:** "괜히 신경 쓰이는데 대놓고 물어보긴 그렇잖아"
3. **차별점:** "공개된 정보만으로, AI가 대신 봐줌"
4. **전환:** 얼리버드 희소성 + 24시간 내 결과 제공 고지(정직성)

### 2.3 절대 금지어 (제품 기획서 계승 + 백래시 방어)
- "외모 분석/등급", "스토킹/감시", "뒷조사" 노출 금지 → "계정 분석", "재미로 확인"
- 특정 실명/실계정을 저격하는 마케팅 소재 금지 (제3자 인격권 리스크)

## 3. 핵심 성장 자산 — "결과 카드 + 공유/추천 루프"

**세 접근안(A·B·C)을 하나로 묶는 단일 자산.** 이게 없으면 바이럴이 안 돈다.

### 3.1 궁금증 갭(curiosity-gap) 결과 카드
- 결과 리포트를 **스크린샷 1장에 최적화**된 공유 카드로 렌더 (세로 9:16, 워터마크에 서비스명+URL).
- **핵심: 고위험 1명을 블러/모자이크 + "🔴 고위험군 발견"** 만 노출. 전체는 본인이 돌려야 보임 → 궁금증이 신규 유입을 만든다.
- 시니컬 2문장 총평의 일부만 티저로 노출("이 분은… 좀 위험합니다").
- **주의:** 카드에 제3자 실계정/실명/얼굴 노출 금지 → 데모 카드는 가상 데이터로.

### 3.2 공유/추천 루프 (referrals 스킬 적용)
- 결과 페이지에 **"친구도 돌려보게 하기"** 공유 버튼(카톡/스레드/X/링크복사, UTM 자동 부착).
- **추천 코드:** 내 링크로 친구가 결제 시 → 나에게 다음 분석 할인 or 맞팔 알리미 무료 1개월. (Phase 2 핵심 루프)
- **바이럴 계수 목표 k ≥ 0.4** (결제자 1명이 평균 0.4명의 신규 결제를 데려옴).

### 3.3 필요한 제품/코드 변경 (→ 후속 writing-plans 대상)
1. 결과 공유 카드 이미지 생성(OG 이미지/다운로드용), 블러 처리
2. 공유 버튼 + UTM 파라미터 스킴 확정
3. 추천 코드 발급/집계 (Supabase)
4. 랜딩/얼리버드 **실시간 잔여 슬롯 카운터**("10명 중 N명 남음") — 희소성 시각화
5. UTM → Amplitude 소스 귀속 이벤트

> 위 5개는 별도 구현 플랜으로 분리. Phase 1은 최소 1·4번만 있어도 시작 가능(수동 카드 + 수동 카운트).

## 4. Phase 1 — 얼리버드 1주 플레이북 (목표: 낯선 사람 10명)

**전략:** 커뮤니티 떡밥으로 궁금증을 퍼뜨리고, 얼리버드 희소성으로 닫는다. `launch` + `community-marketing` + `offers` 적용.

### 4.1 오퍼 설계 (offers 스킬)
- 가격(2026-07-25 개정): **Basic 정가 13,900 → 얼리버드 6,900(50%)**, **Standard 정가 19,900 → 얼리버드 9,900(50%)**, 각 선착순 10.
- **전략적 함의 — 진입장벽 하락:** 최저가 6,900원은 "커피 한 잔 값" 충동구매 구간. 밈·재미 포지셔닝과 정확히 맞물려 방문→결제 CVR 상방을 연다(§1.3 목표치는 보수적 하한, 실측 시 상향 여지). 단, ARPU가 낮아지므로 1,000명 목표는 결제 "수" 자체가 관건 — 슛 횟수·바이럴 루프 의존도가 더 커진다.
- **정직성 고지 유지:** "24시간 내 결과" — 즉시 자동판독 아님을 숨기지 않는다(신뢰 + 클레임 방어).
- **희소성 강화:** "N/10 남음" 실시간 표기 + 마감되면 "대기자 등록(plus waitlist)"으로 수요 흡수.

### 4.2 데이 바이 데이 (7일)
- **D0 (준비):** 결과 데모 카드 3종 제작(가상 데이터), 랜딩 잔여슬롯 표기, 무료 베타테스터(지인) 5~10명에게 실제 분석 돌려 **진짜 후기·스크린샷 확보**(소재 확보용, 결제 아님).
- **D1:** 카카오 오픈채팅 "연애상담/썸/연애고민" 방 3~5개 잠입 → 자연스러운 "썰 + 결과 카드" 1개. 스레드 22명 계정에 티저 포스트 시작.
- **D2:** 여초 커뮤(더쿠/인스티즈) 유머·연애 게시판에 **"썰" 포맷**으로 결과 카드 공유(홍보 아닌 경험담 톤).
- **D3:** 에타 익명 게시판에 "이런 거 있길래 남친 돌려봤다 썰"(직접 링크 지양, 검색 유도).
- **D4:** 반응 좋은 채널 더블다운 + 스레드 콘텐츠 2번째. 첫 결제 발생 모니터링.
- **D5:** "선착순 마감 임박(3자리 남음)" 희소성 푸시 라운드.
- **D6~D7:** 마감 카운트다운 + 대기자 전환. 10명 달성 리뷰.

### 4.3 Phase 1 성공 판정 & 폴백
- 10명 미달 시: (a) 어떤 채널이 방문을 만들었나(UTM) (b) 방문은 있는데 결제가 없으면 오퍼/가격/신뢰 문제 → 랜딩 문구·가격·후기 보강 (c) 방문 자체가 없으면 채널 미스매치 → 여초 커뮤/오픈채팅 침투 심화.

## 6. Phase 2 — 프로덕션 후 30일 1,000명 플레이북

**전략:** "슛 횟수 극대화". 숏폼 엔진을 매일 돌려 breakout 확률을 높이고, 인플루언서로 도달을 사고, 추천 루프로 결제자가 결제자를 부르게 한다.

### 6.1 숏폼 엔진 (접근안 B) — 로드베어링 기둥
- **게시량:** 일 2~3개(월 60~90개). 훅·포맷 A/B 다양화.
- **ABG 크리에이터(섭외 중):** 얼굴 노출 리빌 영상 담당 → 신뢰·몰입 담당. 섭외 확정 시 주 N개 배정.
- **얼굴 비노출 라인:** 화면록화 "남친 판독 결과 리빌" ASMR/리액션 → 병렬 운영으로 슛 횟수 확보.
- **훅 뱅크(예시):** "남친 인스타 이거 돌렸다가 헤어질 뻔", "AI가 여사친 1명 콕 집어줌", "고위험군 뜬 순간 표정".

### 6.2 인플루언서 시딩 (접근안 C, 무페이 우선 → 성과형 확장)
- 연애 유튜버·스레드러·틱토커 마이크로(1만~10만) 대상 **무료 분석권 + 결과 카드** 제공.
- `influencer-marketing` 스킬 적용: 후기 자율성 보장, 추적 링크(추천 코드) 부착.
- 무페이 응답률 낮으면 **성과형(결제당 리워드)** 으로 전환.

### 6.3 추천 루프 (referrals) 본격 가동
- 결제 후 화면에서 추천 코드 발급 → 친구 결제 시 리워드.
- 목표 k ≥ 0.4. 주간 k 모니터링(6.5의 loop).

### 6.4 소스 믹스 목표 (33,000방문/월)
- 숏폼/인플루언서 ~60% / 커뮤·오가닉 리셰어 ~25% / 추천 루프 ~15%.

### 6.5 상시 마케팅 루프 (marketing-loops 스킬)
**주간 루프(매주 1회):**
1. Amplitude 퍼널 리뷰(소스별 방문→결제 CVR, k값)
2. 숏폼 성과 상위 3개 훅 → 다음 주 더블다운, 하위 훅 폐기
3. 커뮤 반응 좋은 떡밥 재활용 / 소진된 떡밥 교체
4. 오퍼·가격·랜딩 카피 1개 A/B
5. 자기점검: breakout 궤도인가? 아니면 훅/채널 재배치

## 7. 트래킹 & 계측 (Amplitude 기반)

- **UTM 스킴:** `utm_source`(채널) / `utm_medium`(community|shortform|influencer|referral) / `utm_campaign`(earlybird|launch) / `utm_content`(소재ID).
- **핵심 이벤트:** 랜딩 조회 → `analysis_started` → 결제 완료 → 결과 공유 클릭 → 추천 유입.
- **대시보드:** 소스별 방문→결제 퍼널, 일별 결제, 잔여 슬롯 소진, 숏폼 조회→방문 귀속.
- **주의:** Amplitude 앱 프로젝트는 MCP 계정에 없음 → 실측 검증은 Dashboard REST API(US, API+Secret키)로 (기존 검증법 계승).

## 8. 리스크 & 가드레일 (전략적 방어 + 윤리)

이 제품은 질투·감시 인접 소재라 백래시가 **실질적 성장 위협**이다(사용자도 디시 백래시 우려). 가드레일은 도덕이자 전략이다.

1. **포지셔닝 고정:** "재미·호기심" 프레임 유지. "감시/뒷조사/스토킹" 프레임 절대 회피 — 백래시·플랫폼 밴·앱스토어 리스크의 핵심.
2. **제3자 인격권:** 마케팅 소재에 실존 인물·실계정·얼굴 노출 금지. 데모는 가상 데이터.
