# 랜딩 트래픽 지연 안내 배너 설계

## 목표

서비스 접속 증가로 분석 대기 시간이 평소보다 길어지고 있음을 랜딩 방문자에게 분석 시작 전에 알린다.

## 사용자 경험

- 랜딩페이지의 기존 `TopBar` 바로 아래에 가로 전체 폭의 운영 공지 배너를 표시한다.
- 문구는 `현재 접속자가 많아 분석 대기 시간이 평소보다 길어지고 있습니다.`로 고정한다.
- 배너는 sticky/fixed로 만들지 않는다. 사용자가 아래로 스크롤하면 자연스럽게 화면 밖으로 사라진다.
- 붉은 계열 배경과 대비되는 밝은 텍스트를 사용해 긴급 공지임을 분명히 한다.
- 모바일에서는 문구가 잘리지 않고 줄바꿈되며, 데스크톱에서는 중앙 정렬한다.

## 범위

- `components/landing-page.tsx`의 랜딩페이지에만 배너를 추가한다.
- 기존 히어로, 판독 절차, 신뢰 블록, CTA 등 확정된 마케팅 카피는 변경하지 않는다.
- 분석·결제·보관함 페이지와 데이터 흐름은 변경하지 않는다.
- 닫기 버튼, 노출 기간 설정, 원격 운영 토글은 이번 긴급 변경 범위에서 제외한다.

## 검증

- 소스 계약 테스트로 정확한 문구, `role="status"`, 랜딩 내 배치, 비고정형 스타일을 검증한다.
- 관련 테스트, 린트, 타입 검사와 프로덕션 빌드를 실행한다.
- 배포 후 실제 도메인의 랜딩페이지가 HTTP 200을 반환하고 배포 자산에 공지 문구가 포함되는지 확인한다.
