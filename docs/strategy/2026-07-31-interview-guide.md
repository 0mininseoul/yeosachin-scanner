| 가설 | 질문 | 판별 위치 |
|---|---|---|
| **H-A** 발견 — 여사친 관계를 잘 몰라서 불안하다 | 실제로 모르나? | §2 |

## 절대 규칙

이 다섯 개를 어기면 인터뷰 데이터가 죽는다. 죽은 데이터는 없는 것보다 나쁘다 — **틀린 확신을 준다.**

1. **제품을 설명하지 않는다. 보여주지도 않는다.** 보여주는 순간 상대는 예의상 반응하기 시작한다. "우리가 이런 걸 만들고 있는데"는 금지어다.
2. **미래를 묻지 않는다.** "이런 게 있으면 쓸래?", "얼마면 살래?"에 대한 답은 전부 거짓말이다. 악의가 아니라 사람이 자기 미래 행동을 예측하지 못하기 때문이다. **과거에 실제로 한 일만 묻는다.**
3. **우리 어휘를 먼저 꺼내지 않는다.** "의심", "위험", "여사친", "판독" — 우리가 먼저 말하면 상대가 그 프레임으로 답한다. 상대가 먼저 그 말을 쓰는지가 데이터다.
4. **의견을 묻지 않는다.** "어떻게 생각해?"가 아니라 "그때 뭐 했어?"
5. **말을 줄인다.** 목표는 상대가 70% 이상 말하는 것. 침묵이 어색해도 기다린다. 가장 중요한 문장은 대개 침묵 다음에 나온다.

### 금지 질문 / 대체 질문

| ❌ 금지 | ✅ 대체 |
|---|---|
| "이런 서비스 있으면 쓸 것 같아?" | "그때 그거 알아보려고 뭐 해봤어?" |
| "얼마면 살 것 같아?" | "연애 관련해서 돈 써본 적 있어? 얼마 냈어?" |
| "남친 여사친 때문에 불안했어?" | "요즘 그 사람 인스타 볼 때 뭐 봐?" |
| "이 기능 어때?" | (제품 언급 자체 금지) |
| "의심되는 계정 있었어?" | "이름이나 얼굴 떠오르는 사람 있어?" |

# Track A — 이탈자 조사: 개인 연락이 아니라 **익명 인앱 설문**

## rev.1의 오류 — 개인 인터뷰는 하면 안 된다

rev.1은 "이탈자 25명에게 개인 연락"을 최우선으로 제안했다. **철회한다.** 소유자 지적이 옳다.

이 서비스는 사용 행위 자체가 떳떳하지 못한 종류다. 남자친구의 인스타그램 아이디를 입력했다는 사실을 **운영자 개인이 알고 있고, 그걸 근거로 개인 연락을 했다**는 것은 유저 입장에서 감시당했다는 신호다. 결과는 인터뷰 거절과 브랜드 손상이다.

**결정적인 이유가 하나 더 있다.** 랜딩이 파는 약속이 *"조회 흔적도, 알림도 남지 않습니다"*(`app/page.tsx`)인데, 운영자가 개인 연락을 하는 순간 **"아무도 모른다"는 약속의 정서적 신뢰가 무너진다.** 기술적으로 다른 약속이지만 유저에게는 같은 종류의 배신이다. 제품의 핵심 소구를 스스로 훼손하면서 얻는 데이터는 값이 없다.

## 대체안 — 익명·자동 인앱 마이크로 설문

같은 질문을 **사람이 아니라 화면이 묻게** 한다.

| 원칙 | 이유 |
|---|---|
| **자동화된 것으로 읽혀야 한다** | "우리가 당신을 봤다"가 아니라 "시스템이 모두에게 묻는다"로 느껴져야 한다 |
| 개인 식별 언급 금지 | "지난주에 들어오셨는데"류의 표현 금지. 그 한 줄이 감시 신호다 |
| 언제든 닫힌다 | 강제하면 이탈 지점이 하나 더 생긴다 |
| 한 문항 | 두 문항부터 응답률이 급락한다 |
| 보상 없음 | 기프티콘을 걸면 응답 편향이 생기고, 무료 이용권은 지불 의사 데이터를 오염시킨다 |

### 노출 위치

플랜 화면 이탈 시도 시(뒤로가기·탭 닫기) 또는 **재방문 시** 1회.

### 문항

> **결제까지는 안 하셨네요. 어떤 점이 망설여지셨어요?** (익명입니다)

| 선택지 | 검증하는 것 |
|---|---|
| 가격이 부담돼서 | 가격 탄력성 |
| **결과가 어떻게 나올지 몰라서** | **샘플 공개 가설** |
| **정확할 것 같지 않아서** | **DM 신뢰도 상한 문제** |
| 그냥 둘러보는 중이었어서 | 재미·호기심 세그먼트 |
| 기타 (주관식 한 줄) | 예상 밖 |

**선택지 순서를 무작위화**한다. 고정 순서는 첫 항목에 응답이 몰린다.

### 이 설문이 개인 인터뷰보다 나은 점

- 사회적 비용 0 — 아무도 노출되지 않는다
- 응답 수가 훨씬 많다 — 25명 중 5명 통화보다 25명 중 12명 클릭이 낫다
- **선택지 4개가 각각 다른 가설에 매핑**되어 있어 분포 자체가 진단이다
- 앞으로 오는 모든 이탈자에게 계속 작동한다 (일회성이 아니다)

### 한계 (인정하고 갈 것)

- 선택지가 우리가 상상한 범위로 답을 가둔다 → **기타 주관식이 이걸 부분적으로 푼다.** 기타 응답은 전부 원문 그대로 보관한다
- "왜"의 깊이가 없다 → 깊이는 Track B에서 얻는다

## 구현 비용

프론트 한 화면 + 이벤트 하나. **분석 파이프라인을 건드리지 않으므로 원가가 발생하지 않는다.**

# Track B — 콜드 문제 인터뷰

제품을 한 번도 본 적 없는 사람. **H-C(단계 조절 가설)를 검증하려면 썸과 연애를 나눠서 모아야 한다.**

## 표본

**6명 = 썸 단계 3명 + 연애 중 3명.**

5명이 아니라 6명인 이유는 단계 비교가 이번 라운드의 핵심 질문이기 때문이다. 통계적 유의성이 목적이 아니라 **두 집단이 눈에 띄게 다른 이야기를 하는지**를 본다. 다르면 H-C 채택, 같으면 단계는 조절 변수가 아니다.

## 스크리너 (섭외 시)

제품을 언급하지 않고 이렇게 묻는다.

> "연애나 썸 관련해서 요즘 어떤지 30분만 얘기 들어보고 싶은데 괜찮아? 서비스 홍보 아니고 그냥 리서치야."

분류 기준:
- **썸 집단**: 현재 썸 중이거나 최근 3개월 내 썸 경험
- **연애 집단**: 현재 연애 중 (기간도 기록 — H-C의 세부 곡선)

## 서비스를 아는 지인을 인터뷰해도 되는가

**된다. 다만 조건이 붙는다.**

아는 것 자체가 실격 사유는 아니다. 문제는 **편향의 종류**다.

| 질문 유형 | 지인 편향 정도 | 예시 |
|---|---|---|
| **과거 행동** | **낮음** — 제품을 알아도 답이 크게 안 바뀐다 | "팔로잉 목록 마지막으로 본 게 언제야", "타로에 얼마 냈어" |
| 의견·평가 | 높음 | "이런 거 어때?" |
| 미래 의향 | **치명적** — 도와주고 싶어서 과장한다 | "이런 거 있으면 쓸 것 같아?" |

**이 가이드는 이미 과거 행동만 묻도록 설계돼 있다.** 그래서 지인이어도 §2~§5의 데이터는 상당 부분 쓸 만하다. 반대로 말하면, 지인을 배제하는 것보다 **미래 의향 질문을 배제하는 것이 훨씬 중요하다.**

### 실무 규칙

1. **모르는 사람을 우선한다.** §6 마지막의 친구 소개 질문이 모르는 사람으로 가는 통로다
2. 아는 사람이면 **기록 시트에 표시하고** 판정 시 가중치를 낮춘다
3. 인터뷰 시작 시 **명시적으로 선을 긋는다** — *"오늘은 내가 만든 거 얘기 안 할 거야. 네 경험만 들을게. 궁금한 거 있으면 끝나고 얘기해줄게."* 이 한 문장이 "도와주기 모드"를 상당히 끈다
4. 인터뷰 중 **제품을 보여주지 않는다.** 이미 본 적 있는 사람이면 그 사실도 기록한다
5. n=6에 솔로 파운더면 전부 배제할 수 없다. **배제보다 표시가 낫다**

### 절대 안 되는 조합

**이미 제품을 써 본 지인**에게 §5(지불 의사)를 묻는 것. 무료로 써 봤다면 가격 감각이 완전히 오염돼 있다. 이 사람은 §2~§4까지만 쓰고 §5는 버린다.

## §1. 워밍업 — 단계 파악

- "요즘 만나는 사람 있어?"
- "어떻게 만났어? 얼마나 됐어?"
- "그 사람 SNS 해? 인스타?"
- **"서로 팔로우는 하고 있어?"** ← *제품 작동 가능성. 특히 썸 집단에서 맞팔이 아직 아니면 제품이 애초에 돌아가지 않는다*

> 여기서 자연스럽게 단계, 상대의 SNS 활동성, **그리고 맞팔 여부**가 잡힌다. 아직 아무것도 묻지 않는다.
>
> **맞팔 여부는 썸 타겟 검토에서 결정적이다.** 썸 단계에서 맞팔 비율이 낮으면 썸 세그먼트는 시장 크기와 무관하게 **기술적으로 도달 불가능**하다.

## §2. 지식 상태 — H-A vs H-B 핵심 판별

**순서를 지킨다. 아래로 갈수록 좁아지고, 앞 질문에서 상대가 먼저 꺼낸 것이 훨씬 강한 데이터다.**

- "그 사람 인스타 얼마나 자주 봐?"
- "볼 때 주로 뭐 봐?" *(→ 여기서 팔로잉/좋아요 얘기가 나오면 상대가 먼저 꺼낸 것)*
- **"그 사람 팔로잉 목록 본 적 있어? 마지막이 언제야?"**
- **"거기 여자 계정 몇 명쯤 있을 것 같아?"** ← *H-A/H-B 1차 판별*
- **"그중에 이름이나 얼굴 떠오르는 사람 있어? 몇 명쯤?"** ← *H-A/H-B 결정적 판별*

### 판정 규칙

| 응답 | 해석 |
|---|---|
| "몰라, 엄청 많아" / 떠오르는 사람 0명 | **H-A (발견)** |
| 대략 규모를 알고, 떠오르는 사람 **1~5명** | **H-B (판정)** |
| 6명 이상 특정 | H-B이되 후보군이 넓음 — 순위의 가치가 커진다 |
| 우리가 묻기 전에 특정 인물을 **먼저** 언급 | **H-B의 가장 강한 증거** |

## §3. 메커니즘 — H-B의 인과 주장 검증

H-B는 "썸 때부터 봐 왔고 연애 중 정보가 쌓인다"고 주장한다. 그게 사실인지 본다.

- "그 사람들 어떻게 알게 됐어?"
- **"썸 탈 때부터 봤어, 아니면 사귀고 나서 봤어?"** ← *H-C 직접 검증*
- "썸 때랑 지금이랑 보는 게 달라?" *(연애 집단에게만)*
- "그 사람 인기 많은 편이야?" ← *기존 가설의 "매력적인 남성일수록" 조절 변수*

## §4. 행동과 대안 — 대안 가용성 검증

- "보고 나서 뭐 했어?"
- "그거 누구한테 말했어?" *(→ 단톡방 대안의 실재)*
- **"그 사람한테 직접 물어본 적 있어?"**
  - 있다면: "물어보니까 어떻게 됐어?"
  - 없다면: **"왜 안 물어봤어?"** ← *가장 중요. 썸 집단이 "사귀는 것도 아닌데 어떻게 물어봐"라고 답하면 대안 부재 가설이 지지된다*
- "안 물어보고 넘어간 다음엔 어떻게 했어?"

## §4-B. 증거 기준 — 무엇을 봐야 '진짜'라고 느끼는가

**이번 라운드에 새로 들어온 가장 중요한 구간이다.**

소유자가 주변에 이 서비스를 설명할 때마다 **첫 질문이 일관되게 "뭘 보고 판단하냐"**였고, **DM을 보느냐**를 물었으며, 좋아요·댓글을 본다고 답하면 **눈에 띄게 실망**했다. 반복적이고, 일관되고, 우리가 유도하지 않은 자발적 반응이다. 이 프로젝트에서 지금까지 나온 외부 신호 중 질이 가장 좋다.

**이게 사실이라면 신뢰도 상한이 구조적이다** — 사람들의 멘탈 모델에서 '증거'는 DM인데 우리는 그걸 볼 수 없다. 좋아요 방향과 댓글 친밀도를 아무리 정교하게 교차해도 *"그건 진짜 증거가 아니잖아"*를 넘지 못한다.

**제품을 언급하지 않고 과거 행동으로 검증한다.**

- "그때 뭘 보고 '아 얘 좀 이상한데' 싶었어?" ← *상대의 실제 증거 위계를 그대로 드러낸다*
- "그거 확인하려고 어디까지 봤어?"
- "봤을 때 제일 결정적이었던 게 뭐야?"
- (상대가 DM·카톡을 언급하면) "그건 어떻게 봤어?" ← *실제로 볼 수 있었는지, 아니면 못 봐서 답답했는지*
- "좋아요나 댓글 같은 건 봤어? 그건 어떻게 느껴졌어?" ← ***마지막에만.*** 앞에서 상대가 먼저 DM을 말했는지가 훨씬 중요한 데이터다

### 판정 규칙

| 응답 패턴 | 해석 |
|---|---|
| 우리가 묻기 전에 **DM·메신저를 먼저** 언급 | **DM 상한 문제 확정.** 진지한 판정 도구 포지션은 약속을 지킬 수 없다 |
| 좋아요·댓글·태그를 스스로 증거로 사용했다고 진술 | 현재 신호 집합이 고객의 증거 기준과 부합. 상한 문제 완화 |
| "그냥 느낌" / 프로필 분위기 | 정확도 요구 자체가 낮음 → 재미 포지션과 정합 |

**이 구간의 결과가 "진지한 유료 판정 도구"와 "저가 재미 바이럴" 중 어느 쪽이 가능한지를 가른다.** 캔버스 ③(UVP)과 ⑥(수익원)이 여기에 달려 있다.

## §5. 지불 의사와 산출물 — 과거 행동만

**미래 의향을 묻지 않고 지불 의사를 재는 유일한 방법은 과거 지출이다.**

- **"연애 관련해서 돈 써본 적 있어? 타로나 사주, 궁합, 연애상담 같은 거."**
- 있다면:
  - **"얼마 냈어?"** ← *가격 앵커*
  - "그때 뭐가 제일 궁금해서 봤어?"
  - "보고 나서 어땠어? 도움 됐어?"
  - **"결과 같은 거 받았어? 캡처해뒀어? 지금도 갖고 있어?"** ← *보고서 파일 가설 검증*
  - "그거 누구한테 보여줬어?" ← *공유 루프*
- 없다면: "돈 낼 만큼은 아니었어? 아니면 그냥 그런 게 있는 줄 몰랐어?"

> **왜 타로·사주인가**: 이게 이 불안에 대해 **실제로 돈이 도는 유일한 비교군**이다. 2~5만원대 지출 이력이 확인되면 현재 6,900~9,900원 가격이 "재미로는 비싸고 신뢰하기엔 싼" 구간에 있다는 캔버스 ⑥의 관측이 지지된다.

## §6. 닫기

- "내가 안 물어본 것 중에 얘기하고 싶은 거 있어?"
- **"이런 얘기 편하게 할 만한 친구 한 명만 소개해줄 수 있어?"** ← *다음 표본 확보. 이게 인터뷰를 지속 가능하게 만든다*

# 종합 판정 기준 (인터뷰 시작 전에 고정)

라운드가 끝난 뒤 기준을 바꾸면 그건 검증이 아니라 사후 해석이다.

| 결론 | 조건 |
|---|---|
| **H-B 채택** | 콜드 6명 중 4명 이상이 특정 인물 1~5명을 지목, 그중 과반이 우리가 묻기 전에 먼저 언급 |
| **H-A 채택** | 콜드 6명 중 4명 이상이 "모른다 / 떠오르는 사람 없다" |
| **H-C 채택** | 썸 3명과 연애 3명의 판정이 **집단별로 갈린다** (예: 썸 = H-A 쪽, 연애 = H-B 쪽) |
| **세그먼트 미성립** | 6명이 서로 완전히 다른 이야기를 한다. → 세그먼트가 아직 존재하지 않는다는 결론이고, 이것도 유효한 결과다 |
| **지불 의사 신호** | 6명 중 3명 이상이 연애 관련 실제 지출 이력 보유. 금액 분포를 가격 앵커로 기록 |
| **샘플 공개 가설** | Track A에서 "뭐가 나올지 몰랐다"류 응답이 과반 |

## 하지 말 것

- 판정 기준을 사후에 옮기기
- 우리 가설에 유리한 응답만 인용하기
- 6명을 다 채우기 전에 결론 내리기
- 인터뷰 결과로 **곧바로 제품을 바꾸기** — 인터뷰는 방향을 좁히는 도구지 설계도가 아니다
